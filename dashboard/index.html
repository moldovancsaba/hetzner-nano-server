Results by evaluation

Choose one cohort at a time. English, image recognition and moderation use different tests; their scores are not interchangeable. Historical screening used a smaller image set than the broader evaluation.

Latency is a historical median for that workload and profile, not a service promise. Valid output means the response met the format contract; it does not establish factual accuracy. Failed or output-budget-limited models are not silently counted as successful.

All attempted model variants

The count includes failed load and inference attempts. Different sizes and quantizations count as distinct variants; repeated tests of the same ID count once. This is not a count of model families or models currently installed.

How to read these results

English ranking uses 14 common structured checks, including answer correctness, JSON validity and tool calls. Broader image recognition uses 32 images. Broader moderation uses 41 images across nine categories; small positive samples limit confidence. Human review remains required.

Non-English capabilities are evaluated independently and are excluded from English scores. These small local evaluations are not general-purpose industry rankings.
